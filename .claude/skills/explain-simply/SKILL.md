# Explain Simply

Explain the target concept so a non-expert can follow it. Optimize for understanding, not thoroughness.

## Rules

1. **Plain words first.** Avoid jargon. If a technical term is unavoidable, define it in the same sentence.
2. **Short sentences, short paragraphs.** One idea per sentence.
3. **Lead with the big picture** — what it is / why it matters — before details.
4. **Use an analogy or concrete example** when it clarifies, but don't force one if it doesn't fit.
5. **Cut anything not needed to understand the core idea.** No caveats, no edge cases, no history, unless asked.
6. **Check length.** If the explanation runs long, it's not simple enough — trim it.

## Don't

- Don't just restate the same content in fewer words with fancier structure — actually reduce conceptual load.
- Don't add headers/bullets for a one-paragraph answer; only structure longer explanations.
- Don't hedge with "it depends" unless the user's actual next step depends on it.
